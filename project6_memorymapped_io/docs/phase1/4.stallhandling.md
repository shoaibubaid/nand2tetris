# 4. Introduce CPU stall/ready handling.

The goal is to make your CPU wait whenever a load/store instruction 
takes multiple cycles.

### Desired behavior: 
1. For a normal arithmetic instruction:

`FETCH → DECODE → EXECUTE → FETCH NEXT INSTRUCTION`

2. For a memory instruction:
```
FETCH → DECODE → EXECUTE
                  |
                  v
            SEND REQUEST
                  |
                  v
             WAIT FOR READY
                  |
             +----+----+
             |         |
           LOAD       STORE
          Capture     Complete
           result     write
             |         |
             +----+----+
                  |
                  v
             FETCH NEXT
```


While waiting:
- The PC must not advance.
- The current instruction must not be replaced.
- The register file must not receive an unintended write.
- No duplicate memory request should be issued.
- The CPU resumes only after the memory controller asserts ready.


We'll likely need to modify:
1. `cpu.v` — introduce memory-wait control and stall instruction execution.
2. `top.v` — connect the memory controller handshake if the current hierarchy requires it.
3. Possibly `next_pc_logic.v` — ensure the PC holds during a stall.
