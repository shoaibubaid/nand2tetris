# Phase 3 - Software infrastructure

## Step 1 — Assembler and machine-code generation

- Parse assembly instructions.
- Encode RISC-V instructions.
- Resolve labels and branch offsets.
- Generate .hex files for instruction memory.
  
## Step 2 — Stack management and function calls
- Stack pointer (sp).
- Function arguments and return values.
- jal and jalr.
- Calling conventions.
  
## Step 3 — Reusable assembly routines
- Graphics and framebuffer operations.
- Keyboard input.
- Timer and delays.
- Reusable functions for the Pong game.
